**部署提醒**：`alembic upgrade head`；生产 `AI_MOCK_MODE=false` + `monitor_probe_mode=api` + `monitor_strict_api=true`；生产 `ALLOW_INSECURE_JWT=false` + 强 `JWT_SECRET` + 非默认 `CONTENT_AGENT_CALLBACK_SECRET`。  
Postgres：一套实例两库 `geo_flow` + `gweb_db`，见 [ADR-017](../../guide/ADR/ADR-017-共享PostgreSQL实例.md)。  
企业 AI：`LLM_GATEWAY_MODE=enterprise-gateway` + `ENTERPRISE_AI_GATEWAY_API_KEY`；见 [ADR-016](../../guide/ADR/ADR-016-企业AI-Gateway主路径.md)。

## 运营动作（有 Key / 切流时执行）

| 动作 | 命令 |
|------|------|
| 企业 Gateway 模型引导 | 配好 Key 后 `python3 scripts/bootstrap_ai_from_env.py` |
| 六平台 Key 矩阵 | `./scripts/smoke_probe_keys.sh` |
| 真 Key 探针 | `GEOFLOW_LIVE_PROBE=1 ./scripts/smoke_probe_keys.sh` |
| 全库重嵌 | `AI_MOCK_MODE=false` 重启后 `python scripts/reindex_all_knowledge.py` |
| 吉利知识库导入 | 配置 `TECHSTORE_DATABASE_URL` 后知识库页按钮，或 `python scripts/import_techstore_knowledge.py` |

不扩：新渠道类型、Admin 全站翻译、三套 CLI 功能。
