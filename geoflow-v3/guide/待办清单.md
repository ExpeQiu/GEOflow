## 技术债与已知限制

- [ ] Monitor 探针当前为 **语料启发式 + LLM 模拟**，非各平台官方 Search API
- [ ] `AI_MOCK_MODE=true` 为默认，生产需显式关闭并配置真实模型 Key
- [ ] LLM 探针模式仅处理前 5 个高优先级问题（防 rate limit）
- [ ] 图片/知识库上传无病毒扫描与 MIME 深度校验
- [ ] 部分 Alembic 迁移需手动 `upgrade head`（006 engine 列）
- [ ] Gweb 同步、技术品牌指标依赖外部数据源，需单独联调
