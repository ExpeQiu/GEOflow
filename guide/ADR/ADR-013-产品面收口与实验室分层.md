# ADR-013：产品面收口与实验室分层

- 状态：Accepted
- 日期：2026-08-26
- 相关：[ADR-010 Theme](./ADR-010-Theme主题包主链路.md)、[ADR-011 Wiki 编辑台](./ADR-011-GEOweb-Wiki轻量编辑台.md)、[ADR-012 三层探针](./ADR-012-三层探针scheme与tracks.md)

## 决策

默认体验只暴露一条技术品牌主链路；其余能力保留 API 与旧 URL，入口收到 **实验室**。

```
问题库 → open_api 日扫 → 场景缺口 → Theme 确认 → Wiki 复合包 → 硬门禁 → GEOweb → 再扫 lift
```

## 分层

| 层 | 一级导航 | 实验室（下拉 / 折叠） |
|----|----------|----------------------|
| L1 | 诊断、探针、场景图谱、挖掘主题、报告 | 可见性明细、优化/难度、销售口径、外部信源；探针内框架/引用/C 端/金标 |
| L2 | 主题包、内容任务、知识库 | 总览、内容工厂、素材、GEO 仿真 |
| L3 | Wiki、分发 | 总览、文章 CMS、运营数据、引用分析 |

主导航一级 Tab 合计 **10**（5+3+2）。旧路径不删。

## 默认值

| 项 | 新默认 | 存量 |
|----|--------|------|
| 缺口建战役 | 只出 Theme 草稿；`legacy_direct_task=true` → 410 | 已有 Task 不动 |
| `content_pipeline_mode` | 新建 `pipeline` | 库内 `legacy` 仍按原值跑 |
| 新建渠道 | UI 只露出 `geoweb`；WP/HTTP/Agent 需「显示高级渠道」 | 已有渠道保留 |
| 缺口 Theme `gate_mode` | `hard`（已由 ADR-010 落地） | 可人工改 soft |

## 冻结（本波不投新功能，已收口为可验收）

- 仓内 `RAG-CLI` / `Sim-sandbox-CLI` / `content-LangGraph-CLI`：归档外挂；`./start.sh` 只跑 verify，主栈不安装
- Admin 六语言：顶栏/登录可切换 zh/en/ja/ko/de/fr；**完整文案仍为中文**，其它语言回退正文
- 新 Connector / 新渠道类型：不新增；Open API 仅豆包/DeepSeek/Kimi，通义/文心/元宝走 C 端
- 文章 CMS：兼容路由保留，仪表盘/总览主入口改为 Wiki

## 待 UAT（有脚本，真 Key 按环境跳过）

- 六平台：`./scripts/smoke_probe_keys.sh`；真扫 `GEOFLOW_LIVE_PROBE=1`
- 全库重嵌：关 `AI_MOCK_MODE` 后 `python scripts/reindex_all_knowledge.py` 或知识库「全库重嵌」
- 吉利知识库：`TECHSTORE_DATABASE_URL` + `/production/knowledge`「导入吉利知识库」（[ADR-014](./ADR-014-Techstore知识库导入.md)）

## 主闭环（复测）

已落地、本波只补日志/单测：

- Wiki `sync-pack` 硬门禁查 `pack_gate_ok`
- 分发编排 / 单篇 publish 认 Theme hard gate
- 再扫后 `_complete_theme_after_lift` → `theme.status=completed`
- 生产注入 `mining_prompt_block`（含 framework 维度）
- Worker/Beat：`start-all.sh` 已拉起

## 后果

- 运营不再在文章 vs Wiki、四套探针、多渠道之间做默认选择
- 实验室功能仍可直链打开（如 `/strategy/sales-copy`）
- 日志键：`theme_id` / `pack_gate_ok` / `remediation_id` / `run_id`
