# GEOFlow 用户使用操作指南

> 本文面向**内容运营、技术品牌团队、策略分析人员**等日常使用 GEOFlow 管理后台的用户。  
> 不涉及开发部署与代码细节；技术文档见 [v3 架构](../geoflow-v3/guide/architecture.md)、[ADR-013 产品面收口](ADR/ADR-013-产品面收口与实验室分层.md)、[GEOweb 集成](geoweb-integration.md)。  
> 可视化版：[docs/用户使用操作指南.html](../docs/用户使用操作指南.html)

## 一、GEOFlow 是什么

GEOFlow 是一套 **GEO（生成式引擎优化）内容工程平台**，帮助团队：

- 用 **AIVIS** 诊断品牌/产品在 AI 平台的可见性（探针 → 场景 → 报告）
- 用 AI **批量生产**高质量内容（文章或 Wiki 百科页）
- 结合**知识库**注入真实业务资料，减少「空泛生成」
- 通过**任务调度**按节奏自动产出、审核、发布
- 将内容**分发**到 **GEOweb**（WordPress 等高级渠道在实验室，默认不露出）
- 用**补缺闭环**（发布 → 再扫 → ΔTop3/lift）证明优化效果

| 运营模式 | 读者访问 |
|----------|----------|
| 通用内容站 | 本站公开前台（可选开启） |
| 技术品牌 / Wiki 模式 | **GEOweb** 官方技术发布站（GEOFlow 负责生产与同步） |

日常操作均在 **管理后台（geoflow-admin）** 完成。本地默认：`http://127.0.0.1:13001/login`。

## 二、登录与界面总览

### 2.1 访问与登录

1. 打开管理后台地址（运维提供）
2. 输入管理员账号和密码
3. 进入 **首页（仪表盘）**

> 演示默认 `admin` / `password`，**生产务必修改**。  
> 顶栏可切换六种语言（实验室）：仅导航/登录翻译，页面正文仍为中文。

### 2.2 顶部主导航

| 导航 | 业务层 | 主要职责 | 默认入口 |
|------|--------|----------|----------|
| **首页** | — | 健康卡片、快速开始、自动化工作流 | `/dashboard` |
| **策略与分析** | L1 · AIVIS | 诊断、探针日扫、场景图谱、挖掘主题、报告 | `/strategy/diagnosis` |
| **内容生产** | L2 | 主题包、内容任务、知识库 | `/production/themes` |
| **运营与分发** | L3 | Wiki 定稿、GEOweb 分发 | `/operations/wiki` |
| **网站设置** | 系统 | 站点、管理员、安全、API Token | 右上角用户菜单 → 系统设置 |

### 2.3 核心业务闭环

```
探针日扫 / 场景缺口 → 挖掘主题 → 确认主题包 → 知识库注入 → 启生产
  → Wiki 定稿 → 硬门禁 → GEOweb 分发 → 再扫验证 ΔTop3 / lift
```

## 三、首页（仪表盘）

路径：`/dashboard`

- **健康卡片**：任务队列、内容资产、分发渠道、今日访问
- **快速开始**：配置 API → **探针日扫** → **主题包确认并启生产** → Wiki 分发
- **三层入口**：L1 策略洞察 / L2 内容生产 / L3 运营主链路
- **GEO 自动化工作流**：按依赖显示阻塞项与建议动作

## 四、策略与分析（L1 · AIVIS）

Hub 标题：**AI 可见性诊断 (AIVIS)**。路径：`/strategy/*`  
一级导航：**诊断 → 探针 → 场景图谱 → 挖掘主题 → 诊断报告**（可见性摘要在诊断页）。  
实验室下拉：可见性明细 / 优化 / 难度 / 销售口径 / 外部信源。  
（旧路径 `/strategy/overview`、`/strategy/monitor`、`/strategy/analytics`、`/strategy/simulator` 会自动跳转）

| Tab | 路径 | 用途 |
|-----|------|------|
| 诊断总览 | `/strategy/diagnosis` | **北极星 KPI** + 可见性摘要 + 补缺闭环 |
| **探针** | `/strategy/probes` | 默认 open_api 日扫；问题库；实验室：交叉/金标/设置 |
| 场景图谱 | `/strategy/scene-graph` | 画像→场景→意图→Query |
| **挖掘主题** | `/strategy/theme-mining` | 差距 → 长尾主题草稿 |
| 诊断报告 | `/strategy/reports` | 北极星章、质量灯、信源、闭环验证 |
| **实验室** | 下拉 | 可见性 / 优化策略 / 难度 / 销售口径 / 外部信源 |

旧路径（`/strategy/collection`、`question-bank`、`brand`、`product` 等）会自动跳转到合并页。

> **运营数据**在实验室 → `/operations/analytics`。  
> **GEO 仿真**在实验室 → `/production/geo-eval`。可见性明细：`/strategy/visibility`。

### 4.1 北极星 KPI（主数字）

口径默认 `open_api`（Chat API），**不等于** C 端 App 联网搜索结果。

| 指标 | 含义 |
|------|------|
| Top3 概率 | 对比+决策题、可解析 rank 样本进前三占比 |
| 相对竞品 pp | 自有 Top3 − 最强竞品 Top3 |
| 参数一致率 | 答文参数 vs 技术 IP SSOT；硬门槛建议 ≥95% |
| 提及率 | 品牌是否被提及；附负向情感占比 |

### 4.2 探针生产建议

- `monitor_probe_mode=api`，`monitor_strict_api=true`
- `AI_MOCK_MODE=false`
- 平台如豆包、DeepSeek 需配置真实 Key
- **C 端金标（辅轨）**：采集页「C端金标扫描」或 `POST /api/admin/strategy/cend/scan`；需 `pip install -e '.[cend]'` + `playwright install chromium`，人工扫码登录持久 Profile（`CEND_PROFILE_ROOT`）；联调可 `CEND_MOCK_MODE=true`

### 4.3 真实闭环（场景补缺 → Theme）

```
高缺口场景 → 生成主题草稿（人工确认）
  → 确认规格（标题库 + Task + remediation）→ 启动生产
  → 审核/GEO 门禁 → GEOweb 分发成功
  → awaiting_rescan（默认 T+72h）→ 再扫 → ΔTop3 / lift
  → 诊断报告「闭环验证」章
```

入口：策略 → **挖掘主题**（`/strategy/theme-mining`）→ 内容生产 → **主题包**。  
场景图谱 / 优化策略保留跳转快捷入口。  
草稿含**挖掘摘要**（探针证据 / 思考摘要 / 信源 / 长尾 Query）；确认前先看摘要，可另存候选草稿。  
旧「一键补缺 Task」已移除：`legacy_direct_task=true` 返回 410，只出 Theme 草稿。

### 4.4 本地演示数据

```bash
cd geoflow-v3/backend
.venv/bin/python ../scripts/seed_strategy_demo.py          # 幂等
.venv/bin/python ../scripts/seed_strategy_demo.py --force  # 清旧 demo 重种
```

会写入：品牌「吉利汽车」+ 竞品、3 个场景 / 9 道探针题、45 条演示探针（含思考链/信源）、高缺口场景主题草稿。便于走通 诊断 → 探针 → 可见性 → 场景图谱 → 挖掘主题。

## 五、内容生产（L2）

路径：`/production/*`

| Tab | 路径 | 说明 |
|-----|------|------|
| **主题包** | `/production/themes` | 挖掘摘要、Query 确认、门禁聚合、确认/启生产 |
| **内容任务** | `/production/tasks` | 内容生成任务列表与启停 |
| 知识库管理 | `/production/knowledge` | RAG、设置、技术 IP |
| **实验室** | 下拉 | 总览、内容工厂、素材（遗产 CMS）、GEO 仿真 |

### 5.0 内容生产主入口（主题包优先）

主路径：`/production/themes` — 选挖掘草稿 → 确认规格（自动建标题库 + Task）→ 启生产。  
选题来自主题包长尾 Query，**不要**用监控题或「KB Smoke」标题库替代。

旁路（调试）：`/production/tasks/new` 可手工选标题库建任务，页面内已标明为非主链路。  
新建任务默认仅本站生成；**分发**请到运营 → 分发任务。

### 5.1 内容工厂（实验室）

路径在实验室下拉：`/production/ai_config`。日常战役不从这里起步。

| 子页 | 路径 |
|------|------|
| Content Agent 编排 | `/production/ai_config` |
| AI 模型 | `/production/ai-models` |
| 提示词模板 | `/production/ai-prompts` |
| Agent 配置 | `/production/ai-agents` |

- **Chat** 至少一个；用知识库时还需 **Embedding**
- 新建任务默认 **编辑部 Pipeline**（存量 `legacy` 仍按库内值跑）

### 5.2 素材库（遗产 CMS）

导航已收入实验室。新战役请走 **主题包 + 知识库**；本页仅维护存量分类/标题库。

1. **分类**（存量任务需要）→ 2. **标题库** → 3. **关键词** → 4. 图片/作者（可选）

### 5.3 知识库

新建 → 上传/粘贴（`.txt` / `.md` / `.pdf` 等）→ **同步切片** → RAG 沙箱验证 → 任务绑定。  
技术 IP：`/production/tech-assets`（Wiki 与参数 SSOT）。  
**吉利知识库**：知识库页「导入吉利知识库」从 Techstore 只读灌入（按领域拆 KB + 技术 IP）。需配置 `TECHSTORE_DATABASE_URL`；未配置则导入演示语料。CLI：`python scripts/import_techstore_knowledge.py`。  
关 Mock 后全库重嵌：知识库页「全库重嵌」，或 `python scripts/reindex_all_knowledge.py`。

### 5.4 GEO 标准（内容门禁）

| 模式 | 行为 |
|------|------|
| **软门禁** | 未达阈值 → 「建议改进」，**不拦**发布/自动分发 |
| **硬门禁（Wiki 战役默认）** | 缺口 Theme `gate_mode=hard`；未通过则拦截 Wiki 同步与分发 |
| 双轨口径 | 内容门禁 ≠ 探针 open_api KPI，互不覆盖 |

Wiki 合规（技术品牌）：结论、表格、内链、FAQ、证据链等。

## 六、运营与分发（L3）

路径：`/operations/*`  
一级导航：**Wiki**、**分发**。实验室：总览 / 文章 CMS / 运营数据 / 引用分析。

Wiki / 分发 jobs 可按 **Theme ID** 筛选；`gate_mode=hard` 未过门禁时标「待门禁」。

| Tab | 路径 |
|-----|------|
| **Wiki** | `/operations/wiki` |
| 分发管理 | `/operations/distribution` |
| **分发任务** | `/operations/distribution/tasks` |
| **实验室** | 文章 `/operations/articles`、运营数据 `/operations/analytics`、引用分析 |

### 6.1 分发任务管理

路径：`/operations/distribution/tasks` — 选择已发布文章 → 活跃渠道 → 节奏（立即 / 错峰间隔）→ 入队。  
内容生成请到 **内容生产 → 内容任务**（`/production/tasks`）。  
旧路径 `/operations/tasks*` 已重定向到内容任务。

### 6.2 文章（实验室 / 兼容路由）

路径 `/operations/articles` 仍可用，**不是**新战役入口。日常定稿走 **Wiki**。

```
生成/手动 → 草稿 → 待审（可选）→ 发布 → 回收站
```

软门禁下「建议改进」通常仍可发布。

### 6.3 分发渠道

新建渠道默认只露出 **GEOweb**。WordPress / HTTP / Agent 需勾选「显示高级渠道」。  
队列：`/operations/distribution/jobs`。

### 6.4 引用分析

对照探针结果，看已分发文章是否被 AI 回答引用（可见性、来源、平台、索引状态）。

### 6.5 运营数据

路径：`/operations/analytics`

- 文章总量 / 已发布 / 浏览 / 活跃任务
- 近 7 日产量趋势、AI 调用与队列健康
- 热门内容、AIVIS 洞察与可见性趋势（运营复盘视角）

> 原首页与策略侧「数据分析」入口均已指向此处。

## 八、典型业务场景

### A. 技术品牌主闭环（默认）

问题库 → open_api 日扫 → 场景缺口 → **主题包确认** → Wiki 复合包 → 硬门禁 → GEOweb → 再扫 lift。  
周报看北极星 KPI。

### B. 知识库增强

上传资料 → 同步切片 → 任务绑定知识库 → 编辑部 Pipeline。RAG 沙箱在知识库实验室。

### C. 多站点 WordPress（实验室渠道）

勾选「显示高级渠道」后新建 WP 渠道 → 分发入队 → 排查失败。新战役默认仍走 GEOweb。

### D. 技术品牌 Wiki → GEOweb

技术 IP → 主题包硬门禁 → Wiki sync-pack → GEOweb。

### E. AIVIS 补缺闭环

探针 api+strict → 问题库 → 日扫 → 挖掘主题出 Theme 草稿 → 确认生产 → Wiki 分发 → 再扫 ΔTop3。

### F. 单篇精修（实验室）

`/operations/articles` 新建 → Markdown/SEO → 审核发布。日常定稿请走 Wiki。

## 九、关键概念速查

| 术语 | 通俗解释 |
|------|----------|
| **GEO** | 让内容更容易被 AI 引用和推荐 |
| **AIVIS** | AI 可见性诊断：探针 → 可见性 → 场景 → 优化 → 报告 |
| **北极星 KPI** | Top3、相对竞品 pp、参数一致率、提及率（open_api） |
| **任务** | 自动生产调度单元 |
| **RAG** | 知识库片段注入生成上下文 |
| **GEO 标准 / 门禁** | 内容评分；Wiki 战役默认硬门禁 |
| **探针** | 向 AI 平台提问监测排名（默认 open_api 日扫） |
| **补缺 / remediation** | 高缺口建 Theme 草稿，再扫证明 lift |
| **技术 IP** | Wiki 技术点身份证与参数 SSOT |
| **Wiki MDX** | 面向 GEOweb 的百科页格式 |
| **引用分析** | 分发内容是否被 AI 回答引用 |
| **Content Agent** | 多步写作流水线 |

## 十、常见问题

**Q1 尚未配置分类** → 存量 CMS 任务才需要；新战役走主题包，不必先建素材分类。

**Q2 知识库待向量化** → 实验室内容工厂配置 Embedding → 同步切片。

**Q3 任务无产出** → 启用状态、标题剩余、生成上限、失败队列。

**Q4 「建议改进」能否发布？** → 软门禁可以；Wiki 战役硬门禁会拦截 sync-pack / 分发。

**Q5 Wiki/文章未进 GEOweb** → 绑定 `geoweb` 渠道 + 已发布 + `GEOWEB_SYNC_ENABLED` + Token 一致。

**Q6 人工审核与发布间隔** → 审核模式下自动发布间隔不可用。

**Q7 Mock / 语料探针质量差** → 关 `AI_MOCK_MODE`，探针 `api` + strict。

**Q8 北极星 vs App 结果不同** → 主 KPI 是 open_api Chat 口径，报告脚注说明偏移。
