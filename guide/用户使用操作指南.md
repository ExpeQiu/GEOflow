# GEOFlow 用户使用操作指南

> 本文面向**内容运营、技术品牌团队、策略分析人员**等日常使用 GEOFlow 管理后台的用户。  
> 不涉及开发部署与代码细节；技术文档见 [v3 架构](../geoflow-v3/guide/architecture.md)、[Gweb 集成](gweb-integration.md)。

---

## 一、GEOFlow 是什么

GEOFlow 是一套 **GEO（生成式引擎优化）内容工程平台**，帮助团队：

- 用 AI **批量生产**高质量内容（文章或 Wiki 百科页）
- 结合**知识库**注入真实业务资料，减少「空泛生成」
- 通过**任务调度**按节奏自动产出、审核、发布
- 将内容**分发**到多个远端站点（WordPress、Gweb Wiki 等）
- 用**监控、诊断、仿真**持续优化内容在 AI 搜索中的可见度

**读者在哪里看内容？**

| 运营模式 | 读者访问 |
|----------|----------|
| 通用内容站 | 本站公开前台（可选开启） |
| 技术品牌 / Wiki 模式 | **Gweb** 独立 Wiki 站点（GEOFlow 负责生产与同步） |

日常操作均在 **管理后台（geoflow-admin）** 完成。

## 二、登录与界面总览

### 2.1 访问与登录

1. 在浏览器打开管理后台地址（由运维提供，本地默认 `http://127.0.0.1:13001/login`）
2. 输入管理员账号和密码
3. 登录成功后自动进入 **首页（仪表盘）**

> 首次使用请联系系统管理员获取账号。演示环境常见默认账号为 `admin` / `password`，**生产环境务必修改**。

### 2.2 顶部主导航（五大模块）

登录后，页面顶部始终可见五个入口：

| 导航 | 业务层 | 主要职责 |
|------|--------|----------|
| **首页** | — | 数据概览、快速开始、自动化工作流状态 |
| **内容生产** | L2 | 知识库、素材库、AI 模型与提示词 |
| **运营与分发** | L3 | 任务、文章审核发布、多站点分发 |
| **策略与分析** | L1 | 监控排名、GEO 诊断、数据分析、外部信源 |
| **网站设置** | 系统 | 站点信息、管理员、安全、API Token |

每个 Hub 页面内还有**二级 Tab**，用于在同一业务域内切换子功能。

### 2.3 核心业务闭环

理解这一条主链路，有助于快速上手：

```
配置 AI 模型 → 准备素材 / 知识库 → 创建并启用任务
    → AI 自动生成草稿 → （可选）人工审核 → GEO 评估门禁
    → 发布 → 分发到远端渠道 → 策略分析复盘
```

首页的 **「快速开始」** 和 **「GEO 自动化工作流」** 会实时反映上述各环节是否就绪；有阻塞项时会给出建议动作，点击可跳转到对应模块。

## 三、首页（仪表盘）

路径：**首页** `/dashboard`

### 3.1 健康卡片

页面顶部四张卡片，快速感知系统运行状态：

| 卡片 | 含义 |
|------|------|
| **任务队列** | 运行中 / 排队 / 失败的任务数 |
| **内容资产** | 已发布 / 草稿 / 待审文章数 |
| **分发渠道** | 活跃渠道 / 待分发 / 失败数 |
| **今日访问** | 访问量与 AI 调用次数 |

### 3.2 三层能力入口

- **L1 策略洞察**：监控排名、外部信源、GEO 仿真
- **L2 内容生产**：知识库、素材、AI 配置
- **L3 运营主链路**：任务、文章、分发

点击卡片可进入对应 Hub 总览页。

### 3.3 快速开始（三步）

1. **配置 API** → 跳转 AI 配置器，添加至少一个聊天模型（使用知识库 RAG 时还需 embedding 模型）
2. **配置素材库** → 维护标题库、关键词库、分类等
3. **新建任务** → 跳转任务创建页，启动自动生产

### 3.4 运营车道

- **单站点运营**：本站从配置到发布的完整流程
- **多站点分发**：渠道接入与远端同步
- **数据反馈**：访问、GEO 诊断与风险项

## 四、内容生产（L2）

路径：**内容生产** → 各子 Tab

> 内容生产是「喂料」环节：任务生成文章时，会从这里读取模型、提示词、标题、关键词、知识库片段等。

### 4.1 总览

路径：`/production/overview`

查看素材库数量、知识库健康度、AI 调用统计等汇总信息，作为进入各子模块前的「体检报告」。

### 4.2 AI 配置器

路径：`/production/ai_config`

#### 4.2.1 添加 AI 模型

1. 进入 **AI 模型** 区域，点击新建
2. 填写模型名称、提供商、模型 ID
3. 填入 API Key（系统加密存储，界面不回显明文）
4. 选择模型类型：
   - **Chat**：正文生成（必填至少一个）
   - **Embedding**：知识库向量化与 RAG 召回（使用知识库时必填）
5. 保存并确认模型状态可用

#### 4.2.2 管理提示词模板

1. 进入 **提示词模板** 区域
2. 新建或编辑模板，区分用途：
   - 普通文章正文生成
   - Wiki 专用（概念页 / 对比页 / 指南页 / 数据页等）
3. 在模板中写明角色、结构要求、GEO 写作规范
4. 创建任务时选择对应提示词

#### 4.2.3 Content Agent 编排（可选）

系统支持多步 AI 编排（如「编辑部 Pipeline」：大纲 → 初稿 → 润色）。在编排面板可查看当前工作流拓扑与健康状态。日常运营通常使用默认编排即可；高级用户可与管理员确认 `Legacy 单步` 与 `编辑部 Pipeline` 的差异。

### 4.3 素材管理

路径：`/production/materials`

素材库为任务提供结构化输入，建议按以下顺序初始化：

#### 第一步：文章分类（必做）

路径：`/production/materials/categories`

- 创建内容分类（如「行业资讯」「产品解读」「技术百科」）
- **至少创建一个分类**，否则无法创建任务

#### 第二步：标题库

路径：`/production/materials/titles`

1. 新建标题库（如「每日 GEO 选题」）
2. 批量添加标题，或逐条录入
3. 任务执行时从库中依次或随机取用标题

#### 第三步：关键词库（推荐）

路径：`/production/materials/keywords`

- 按主题维护关键词组
- 开启任务的「自动生成关键词」时，系统会结合关键词库与正文生成 SEO 关键词

#### 第四步：图片库与作者（可选）

| 模块 | 路径 | 用途 |
|------|------|------|
| 图片库 | `/production/materials/images` | 任务配图时随机或指定选用 |
| 作者 | `/production/materials/authors` | 文章署名；任务可设「随机作者」 |

#### 第五步：提示词快捷入口

素材总览页也可跳转至 AI 配置器中的提示词管理。

### 4.4 知识库（RAG）

路径：`/production/knowledge`

知识库让 AI 生成时引用**真实业务资料**，降低幻觉、提升 GEO 可信度。

#### 4.4.1 新建知识库

1. 点击 **新建知识库**
2. 填写名称与描述
3. 录入方式二选一：
   - 直接粘贴文本 / Markdown
   - 上传文件（支持 `.txt`、`.md`、`.pdf`）
4. 保存

#### 4.4.2 切片与向量化

1. 在知识库列表找到目标库，查看切片进度（如 `切片 12/12 已向量化`）
2. 若状态为「待向量化」，点击 **同步切片**
3. 确保已配置 **Embedding 模型**，否则无法完成向量化

#### 4.4.3 知识设置

路径：`/production/knowledge-settings`

可调整：

- 切片大小与重叠
- 检索返回条数
- 是否开启混合检索

修改参数后，建议对相关知识库重新 **同步切片**。

#### 4.4.4 RAG 沙箱（验证召回）

路径：`/production/rag-sandbox`

1. 选择知识库
2. 输入测试查询（如「我们的电池技术优势是什么」）
3. 查看召回片段与相关度分数
4. 召回质量不佳时，回到知识库补充内容或调整知识设置

#### 4.4.5 URL 导入

路径：`/production/url-import`

- 输入网页 URL，系统将抓取并导入为知识库内容
- 可在任务列表查看导入进度

### 4.5 技术 IP 资产（技术品牌模式）

路径：`/production/tech-assets`

用于维护企业技术点「资产卡」，是 Wiki MDX 内容的核心索引：

| 字段 | 说明 |
|------|------|
| **ip_id** | 技术 IP 唯一标识 |
| **名称 / 描述** | 对外展示的技术点名称与摘要 |
| **Wiki 类型** | 概念、对比、指南、数据等 |
| **优先级** | P0 / P1 等，影响策略 KPI 统计 |

**操作步骤：**

1. 点击 **新建资产** 填写信息
2. 或使用 YAML 批量导入（适合一次性初始化大量技术点）
3. 创建 Wiki 任务时绑定对应技术 IP

## 五、运营与分发（L3）

路径：**运营与分发** → 各子 Tab

这是日常最频繁的模块：创建任务、看生成结果、审核发布、推送到远端。

### 5.1 总览

路径：`/operations/overview`

展示启用任务数、待审核文章、待分发队列、Celery 队列健康度等，便于每日巡检。

### 5.2 任务管理

路径：`/operations/tasks`

#### 5.2.1 任务是什么

**任务（Task）** 是自动内容生产的「调度中心」。启用后，系统按设定频率从标题库取题、调用 AI 生成、（可选）进入审核、通过 GEO 门禁后发布，并推送到分发渠道。

#### 5.2.2 创建任务（逐步操作）

路径：`/operations/tasks/new`

**区块一：基本信息**

| 字段 | 说明 |
|------|------|
| 任务名称 | 便于识别的名称，如「每日 GEO 资讯」 |
| 标题库 | 必选，决定生成什么题目 |
| 任务状态 | 创建时可选「启用」或「暂停」 |

**区块二：内容格式**

| 选项 | 适用场景 |
|------|----------|
| **普通文章** | 博客、资讯站 |
| **Wiki MDX** | 技术品牌百科，同步到 Gweb；发布范围自动锁定为「仅分发」 |

选择 Wiki MDX 时需额外指定：

- **Wiki 类型**（概念 / 对比 / 指南 / 数据）
- **技术 IP 资产**（绑定对应资产卡）

**区块三：内容生成**

| 字段 | 说明 |
|------|------|
| 正文提示词 | 必选 |
| AI 模型 | 必选；可选「智能 failover」在模型异常时切换 |
| 编排模式 | Legacy 单步 / 编辑部 Pipeline / 自动 |
| 知识库 | 可选；绑定后生成时注入 RAG 上下文 |
| 作者 | 可选固定作者，或随机 |

**区块四：配图（可选）**

- 选择图片库与配图数量；不选则不配图

**区块五：发布策略**

| 字段 | 说明 |
|------|------|
| 生成后需人工审核 | 开启后文章进入「待审」，**不可**使用自动发布间隔 |
| 发布间隔（分钟） | 关闭人工审核时，相邻两篇自动发布的最小间隔 |

**区块六：分发范围**

| 选项 | 含义 |
|------|------|
| **本站 + 分发** | 本地发布并同步到所选渠道 |
| **仅本站** | 不在远端发布 |
| **仅分发** | 只推送到远端渠道（Wiki 任务固定为此项） |

「仅分发」或「本站 + 分发」模式下，需勾选至少一个**活跃分发渠道**。

**区块七：高级选项**

| 字段 | 说明 |
|------|------|
| 生成上限 | 任务累计最多生成多少篇 |
| 草稿上限 | 同时保留的草稿上限（不能大于生成上限） |
| 循环执行 | 按间隔重复执行 |
| 自动生成关键词 / 描述 | 减轻手工 SEO 工作 |
| 分类策略 | 智能 / 固定 / 随机；固定模式需选分类 |

填写完成后点击 **创建任务**。

#### 5.2.3 管理已有任务

在任务列表可对每条任务：

| 操作 | 说明 |
|------|------|
| **启动 / 暂停** | 控制是否参与调度 |
| **立即执行** | 不等下一轮调度，马上跑一轮生成 |
| **编辑** | 修改模型、素材、发布策略等 |
| 查看统计 | 已生成数 / 上限、已发布数、循环次数 |

任务执行状态支持实时刷新（WebSocket 推送），无需手动反复刷新页面。

#### 5.2.4 创建任务的前置检查清单

在点击「创建任务」前，确认：

- [ ] 至少一个 **文章分类**
- [ ] 至少一个 **标题库**（库内有标题）
- [ ] 至少一个 **提示词模板**
- [ ] 至少一个 **AI 聊天模型**
- [ ] 若使用知识库：Embedding 模型已配置且知识库已向量化
- [ ] 若「仅分发」：至少一个 **活跃分发渠道**
- [ ] 若 Wiki MDX：已配置 **技术 IP 资产** 与 **GWeb Wiki 渠道**

### 5.3 文章管理

路径：`/operations/articles`

#### 5.3.1 文章生命周期

```
AI 生成 / 手动创建 → 草稿 → 待审核（若开启审核）→ 通过审核 → 发布
                                                      ↓
                                                  回收站（可恢复或永久删除）
```

#### 5.3.2 日常审核发布流程

1. 进入文章列表，用 **待审核** 筛选
2. 点击文章标题进入编辑页
3. 检查标题、正文、摘要、关键词、分类
4. 查看 **GEO 评估** 结果：
   - **已通过**：可发布
   - **未通过**：查看失败原因，修改后可在 GEO 诊断中重新评估
   - **待评估**：等待评估完成
5. 点击 **通过审核**（若处于待审状态）
6. 点击 **发布**

列表支持批量感知：状态列、审核列、GEO 列、浏览量一目了然。

#### 5.3.3 手动新建文章

路径：`/operations/articles/new`

适用于单篇精修、活动稿等非任务产出内容：

1. 填写标题、正文（支持 Markdown）
2. 设置分类、作者、SEO 字段
3. 保存为草稿或直接发布

#### 5.3.4 回收站

路径：`/operations/articles/trash`

- **恢复**：文章回到正常列表
- **永久删除**：不可恢复，操作前请确认

### 5.4 分发管理

路径：`/operations/distribution`

#### 5.4.1 分发渠道类型

| 类型 | 适用场景 |
|------|----------|
| **GEOFlow Agent** | 对接另一套 GEOFlow 远端站点 |
| **GWeb Wiki** | 技术品牌 Wiki，同步 MDX 到 Gweb |
| **WordPress REST** | 发布到 WordPress 博客 |
| **通用 HTTP API** | 自定义接口对接 |

#### 5.4.2 新建分发渠道

路径：`/operations/distribution/new`

**通用字段：**

- 渠道名称、目标域名
- API Endpoint（有效的 `http` / `https` 地址）
- 状态：启用 / 暂停

**GWeb Wiki 渠道额外配置：**

- Sync Secret（与 Gweb 约定的 Bearer Token）
- 超时时间

**WordPress 渠道额外配置：**

- 用户名与 Application Password
- 发布状态（草稿 / 发布 / 待审 / 私密）
- 图片策略（上传到媒体库 / 保留原链接）

**通用 HTTP API：**

- 认证方式（无 / Basic / Bearer 等）
- 发布 Method 与 Path

保存后渠道出现在列表；创建任务时勾选即可。

#### 5.4.3 查看分发任务

- 分发总览页展示 **最近分发任务** 与队列状态
- 详细队列：`/operations/distribution/jobs`
- 失败时查看 **错误** 列，修正渠道配置或文章内容后重新发布

## 六、策略与分析（L1）

路径：**策略与分析** → 各子 Tab

用于回答：「内容在 AI 平台表现如何？哪里需要优化？」

### 6.1 总览

路径：`/strategy/overview`

聚合展示：

- GEO 评估与门禁概况
- 技术品牌 KPI（P0 覆盖率、Wiki 合规率、Gweb 同步率、技术 IP 资产数）
- 监控与数据分析快照

### 6.2 监控问题库

路径：`/strategy/monitor`

**用途**：维护一组「探针问题」（如「XX 品牌电池技术怎么样」），定期向多个 AI 平台提问，追踪品牌排名与提及率。

**操作步骤：**

1. 在 **问题库** 中添加监控问题
2. 点击 **全量扫描**，系统对各平台执行探针
3. 在 **最近扫描** 中查看历次运行
4. 点击某次运行进入详情（`/strategy/monitor/runs/[id]`），查看各平台排名与提及情况

**关注指标：**

- 平均排名（越靠前越好）
- 提及率（品牌是否被 AI 回答引用）

### 6.3 外部信源

路径：`/strategy/web-intel`

**用途**：配置外部参考网站，系统抓取并生成洞察报告，了解行业内容被 AI 采纳的特征。

1. 在 **信源列表** 添加 URL
2. 触发刷新 / 入队分析
3. 在 **洞察报告** 中阅读分析结果

### 6.4 仿真与建议

路径：`/strategy/simulator`

- 对单篇或多篇文章进行 **GEO 仿真重评**
- 查看系统给出的优化建议
- 可将建议 **应用到文章**（如补充结构、关键词等）

适合在 GEO 诊断发现大量失败后，批量优化内容。

### 6.5 GEO 诊断

路径：`/strategy/geo-eval`

**用途**：集中查看 GEO 评估引擎与发布门禁状态。

| 功能 | 说明 |
|------|------|
| 门禁状态 | 评估引擎、发布门禁是否启用 |
| 失败原因 Top N | 最常见的不通过原因（如缺少 FAQ、内链不足） |
| 最近失败列表 | 单篇查看并重评 |
| 批量重评失败项 | 内容修改后一键重新评估 |

**Wiki 合规门禁**（技术品牌模式）额外检查：快速结论、表格、内链数量、FAQ 数量、更新日期、Schema、证据链等。

### 6.6 数据分析

路径：`/strategy/analytics`

查看：

- 文章总量、已发布数、总浏览
- 近 7 日新增趋势
- 热门内容排行
- 活跃任务与 AI 调用统计

用于周报、月报与运营复盘。

### 6.7 洞察模板

路径：`/strategy/insight-templates`

**用途**：从优秀外部 URL「挖掘」写作风格，生成 **StyleGuide 模板**，供任务提示词引用。

1. 新建模板，填入参考 URL
2. 系统分析页面结构与文风
3. 在创建任务或编辑提示词时引用该模板

## 九、关键概念速查

| 术语 | 通俗解释 |
|------|----------|
| **GEO** | 让内容更容易被 AI 搜索、问答引擎引用和推荐 |
| **任务（Task）** | 自动生产的调度单元，绑定素材与发布策略 |
| **标题库** | 待生成文章的题目队列 |
| **RAG** | 从知识库检索相关片段，注入 AI 生成上下文 |
| **发布范围** | 本站、远端、或两者同时发布 |
| **GEO 评估 / 门禁** | 发布前自动检查内容是否满足 GEO 规范 |

| **技术 IP 资产** | 企业技术点在 Wiki 体系中的「身份证」 |
| **Wiki MDX** | 面向 Gweb 的结构化百科页面格式 |
| **分发渠道** | 内容发布后的远端同步目标 |
| **Content Agent** | 多步骤 AI 写作流水线（大纲、初稿、润色等） |

## 十、常见问题

### Q1：创建任务时提示「尚未配置分类」

请先到 **内容生产 → 素材管理 → 分类管理** 创建至少一个分类。

### Q2：知识库一直显示「待向量化」

1. 确认已在 AI 配置器中添加 **Embedding 模型**
2. 点击知识库列表的 **同步切片**
3. 仍失败请联系管理员查看后台日志

### Q3：任务启用后没有生成文章

检查：任务是否 **已启用**、标题库是否有剩余标题、是否已达 **生成上限**、队列是否有 **失败** 记录（运营总览 / 首页健康卡片）。

### Q4：文章 GEO 评估未通过无法发布

1. 进入 **策略与分析 → GEO 诊断** 查看失败原因
2. 编辑文章补充结构（如 FAQ、内链、摘要）
3. 单篇 **重新评估** 或批量重评

### Q5：Wiki 内容没有出现在 Gweb

确认：任务为 **Wiki MDX**、渠道类型为 **GWeb Wiki** 且已启用、文章已 **发布**、Wiki 合规门禁已通过、网站设置中 **GWeb 同步** 为已启用。

### Q6：开启「人工审核」后无法设发布间隔

这是预期行为：审核模式下需人工确认后再发布，系统自动发布间隔不可用。可关闭审核改用手动发布，或关闭审核并依赖发布间隔自动上线。

### Q7：演示环境生成内容质量很低

网站设置中若 **AI Mock 模式** 为已启用，系统不会调用真实大模型，仅产出占位内容。正式使用需由管理员关闭 Mock 并配置真实 API Key。
