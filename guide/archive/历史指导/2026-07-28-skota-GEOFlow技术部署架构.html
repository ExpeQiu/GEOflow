注意：本页应清楚描述

  1. 可部署单元分解：admin / api / worker / scheduler / flower / postgres / redis；
  2. 层次与第三方：边缘反代、运行域、缓存队列、持久化、外部 Gweb/LLM/探针；
  3. 数据库与中间件：PostgreSQL+pgvector、Redis；上传默认本地卷；
  4. 监控治理：Flower、/health、verify.sh、request_id 日志（可扩展 Prometheus）；
  5. 跨云/跨境：出站 LLM/探针取决于 Provider 机房，对象与字段见数据安全页；
  6. 若上 K8S，将「运行域」替换为 Namespace+Ingress+Deployment，实例数按右侧建议扩展。
