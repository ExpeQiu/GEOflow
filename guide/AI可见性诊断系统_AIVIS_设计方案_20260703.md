## 一、背景与目标

### 1.1 背景

随着AI助手（豆包、DeepSeek、通义千问等）成为用户获取信息的重要入口，品牌在AI平台上的「可见性」和「推荐率」正在成为继搜索引擎SEO后的新一代品牌营销战场。

加我推荐官提供的AI可见性诊断报告，展示了如何通过系统化的模拟提问+响应分析，量化品牌在AI时代的可见性表现，并给出优化建议。

### 1.2 目标

**建设一套可自动生成AI可见性诊断报告的系统**，实现：
- 多AI平台（豆包、DeepSeek、通义千问、元宝、文心一言、Kimi）的数据采集
- 品牌/产品可见性多维度分析
- 竞品对标矩阵生成
- 场景图谱与内容缺口识别
- 结构化优化建议输出
- 可视化报告自动生成

### 2.2 核心分析维度

| 维度 | 指标 | 计算方式 | 数据来源 |
|------|------|----------|----------|
| **可见性** | Visibility Rate | 品牌出现次数/总提问数 | AI模拟提问 |
| **排名** | Ranking Score | 平均推荐位次（加权） | AI回答解析 |
| **好感度** | Sentiment Score | 正向提及/(正向+负向) | NLP情感分析 |
| **渗透率** | Platform Penetration | 各平台分别统计 | 分平台聚合 |
| **场景覆盖** | Scene Coverage | 有内容支撑的场景数/总场景数 | 内容缺口分析 |
| **竞品差距** | Gap vs Competitor | 与第一名的绝对差距百分点 | 横向对标 |
| **优化潜力** | Optimization Potential | (目标值-当前值)/当前值 | 策略推导 |

## 七、核心算法

### 7.1 可见性计算

```python
def calculate_visibility(mentions: List[str], total_queries: int) -> float:
    """
    可见性 = 品牌提及次数 / 总提问次数 × 100%
    """
    return (len(mentions) / total_queries) * 100

def calculate_platform_visibility(responses: List[AIResponse], brand: str) -> Dict[str, float]:
    """
    分平台可见性
    """
    result = {}
    for platform, response_list in responses.groupby('platform'):
        mentions = sum(1 for r in response_list if brand in r.extracted_brands)
        result[platform] = (mentions / len(response_list)) * 100
    return result
```

### 7.2 排名计算

```python
def calculate_ranking(responses: List[AIResponse], brand: str) -> float:
    """
    排名得分 = Σ(推荐位次 × 权重) / 总出现次数
    权重: 第1位=6分, 第2位=5分...第6位=1分
    """
    weights = {1: 6, 2: 5, 3: 4, 4: 3, 5: 2, 6: 1}
    total_score = 0
    total_mentions = 0
    
    for r in responses:
        if brand in r.extracted_brands:
            position = r.extracted_brands.index(brand) + 1
            total_score += weights.get(position, 0)
            total_mentions += 1
    
    return total_score / total_mentions if total_mentions > 0 else 0
```

```python
def calculate_sentiment_score(mentions: List[Mention]) -> float:
    """
    好感度 = 正向提及 / (正向提及 + 负向提及) × 100%
    """
    positive_count = sum(1 for m in mentions if m.sentiment == 'positive')
    negative_count = sum(1 for m in mentions if m.sentiment == 'negative')
    
    total = positive_count + negative_count
    return (positive_count / total) * 100 if total > 0 else 0
```

### 7.4 优化潜力计算

```python
def calculate_optimization_potential(current: float, benchmark: float) -> Dict[str, float]:
    """
    优化潜力计算
    """
    gap = benchmark - current
    gap_percentage = (gap / benchmark) * 100 if benchmark > 0 else 0
    
    # 达到benchmark需要的提升幅度
    lift_needed = (benchmark - current) / current * 100 if current > 0 else 0
    
    return {
        'gap': gap,
        'gap_percentage': gap_percentage,
        'lift_needed': lift_needed,
        'difficulty_score': min(5, max(1, lift_needed / 20))  # 粗略难度估算
    }
```

## 十、核心难点

| 难点 | 描述 | 解决方案 |
|------|------|----------|
| **平台API不稳定** | 各AI平台无统一接口，反爬严格 | Scrapling动态渲染 + 多账号轮询 |
| **情感判断主观** | 正负向评价标准不统一 | 人工标注训练集 + BERT微调 |
| **场景覆盖黑盒** | AI选择引用逻辑不透明 | 大样本统计 + 归因分析 |
| **内容归因难** | 难以确认AI引用来源 | 搜索引擎内容指纹对比 |
| **实时性要求** | AI平台更新快，数据易过期 | 每周增量 + 月度全量采集 |
