GEOFlow 系统架构

面向 GEO（生成式引擎优化）的开源智能内容工程平台：知识库 → AI 任务 → 审核/门禁 → 发布 → 多站点分发 → 策略分析闭环。

Agent-First · Laravel 单体 + 可选 Python 侧车 · PostgreSQL 真相源

核心业务链路

通用模式（开源默认）

知识库 / 素材 / Prompt → Task 调度 → WorkerExecutionService → RAG 召回 → AI 生成 → 草稿 · 审核 → GEO 门禁 → 本站发布 → DistributionOrchestrator → Analytics

技术品牌模式（GEOFLOW_TECH_BRAND_MODE=true）

TechIpAsset → Wiki Task → wiki_meta + MDX 正文 → WikiGeoComplianceChecker → distribution_only → GwebWikiPublisher → Strategy Hub KPI

业务域（Services）

素材与 RAG

  • KnowledgeBase / KnowledgeChunk + pgvector
  • KnowledgeRetrievalService 混合召回
  • Title / Keyword / Image / Author 库
  • Prompt 模板（正文 / Wiki 四类）

任务与生成

  • TaskLifecycleService · TaskSchedule
  • WorkerExecutionService 核心执行器
  • MarkdownContentWriterAgent（Laravel AI）
  • ContentAgentClient（internal / external）

文章生命周期

  • ArticleWorkflow 状态机
  • review_status · eval_status
  • ArticlePublishService
  • content_format · wiki_meta（Wiki）

多站点分发

  • DistributionOrchestrator
  • GeoFlowAgent / WordPress / Generic HTTP
  • GwebWikiPublisher（技术品牌）
  • ArticleDistribution · DistributionLog

GEO 评估（GeoEval）

  • ArticleEvaluationService 门禁
  • InternalGeoEvalEngine · 模拟 RAG
  • Monitor 探测 · 采纳率聚合
  • InsightTemplate · Web Intel

策略与分析

  • Strategy Hub（L1）
  • GeoEvalAnalyticsService
  • TechBrandMetricsService
  • TrafficClassifier · view_logs
