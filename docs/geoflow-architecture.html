GEOFlow v3 系统架构

面向 GEO（生成式引擎优化）的开源智能内容工程平台：知识库 → AI 任务 → 审核/门禁 → 发布 → 多站点分发 → 策略分析闭环。v3 为当前主开发线，Laravel v2 保留在 v2-lts 分支。

Agent-First · FastAPI 单体 + 内嵌 LangGraph · PostgreSQL 真相源 Laravel v2 → v2-lts / legacy/laravel

核心业务链路

通用模式（开源默认）

知识库 / 素材 / Prompt → Celery schedule_tasks → WorkerExecutionService → RAG 召回 → LangGraph 生成 → 草稿 · 审核 → GEO 门禁 → ArticlePublishService → DistributionOrchestrator → Strategy Analytics

技术品牌模式（GEOFLOW_TECH_BRAND_MODE=true）

TechIpAsset → Wiki Task → wiki_meta + MDX 正文 → WikiComplianceChecker → distribution_only → GwebWikiPublisher → Strategy Hub KPI

业务域（Services）

素材与 RAG

  • KnowledgeBase / KnowledgeChunk + pgvector
  • KnowledgeRetrievalService 混合召回
  • KnowledgeChunkSyncService · embeddings
  • Title / Keyword / Image / Author 库
  • Prompt 模板 · AI 模型配置

任务与生成

  • TaskLifecycleService · Celery Beat 调度
  • WorkerExecutionService 核心执行器
  • workflow_runner · LangGraph 工作流
  • content_pipeline · url_import 工作流

文章生命周期

  • review_status · eval_status 状态机
  • ArticlePublishService
  • try_publish_after_eval 自动发布
  • content_format · wiki_meta（Wiki）

多站点分发

  • DistributionOrchestrator
  • GwebWikiPublisher（gweb_wiki）
  • WordPress REST · Generic HTTP
  • ArticleDistribution · 重试 Job

GEO 评估（GeoEval）

  • ArticleEvaluationService 门禁
  • MonitorScanOrchestrator 日扫
  • WikiComplianceChecker · wiki gate
  • InsightTemplate · Web Intel 抓取

策略与分析

  • Strategy Hub（Monitor · Simulator · GeoEval）
  • Web Intel · insight-templates
  • TechBrandMetrics · adoption 聚合
  • Dashboard · batch 批量操作
