一、GEOFlow 是什么

GEOFlow 是一套 GEO（生成式引擎优化）内容工程平台，帮助团队用 AI 批量生产高质量内容，并结合知识库、任务调度、多站点分发与 AI 可见性诊断形成完整闭环。

核心能力
AIVIS 诊断 → AI 批量生产 → 知识库 RAG → 任务调度 → 审核 · GEO 门禁 → 多站点分发 → 再扫验证 lift

读者在哪里看内容？

运营模式读者访问
通用内容站本站公开前台（可选开启）
技术品牌 / Wiki 模式Gweb 独立 Wiki 站点（GEOFlow 负责生产与同步）
日常操作均在 管理后台（geoflow-admin） 完成，读者不直接访问后台。本地默认入口：http://127.0.0.1:13001/login。

4.1 诊断总览与北极星 KPI

路径：/strategy/diagnosis

页面顶部 北极星 KPI 看板是对外主数字，口径默认 open_api（Chat API 指数，不等于 C 端 App 联网搜索结果）。

指标含义
Top3 概率对比 + 决策题子集中、可解析排名样本进前三的占比
相对竞品 pp自有 Top3 − 最强竞品 Top3（百分点差）
参数一致率答文参数 vs 技术 IP SSOT；硬门槛建议 ≥95%
提及率品牌是否被 AI 回答提及；附负向情感占比

总览同时汇总采集层、品牌/产品层、优化策略层与难度评估层；可一键跳转全量扫描、探针设置、诊断报告、问题库。

4.2 数据采集与探针设置

路径：/strategy/collection

  1. 配置探针模式：生产建议 真实 API（api）+ 开启 strict（禁止静默降级到语料/模拟）
  2. 选择扫描平台（如豆包、DeepSeek）
  3. 点击 全量扫描 或 竞品扫描，等待 Worker 完成
  4. 在最近运行中查看各平台状态与结果
若无品牌类探针，可在采集页使用「补品牌题」。生产环境请关闭 AI_MOCK_MODE，否则可见性数字无业务参考价值。

八、典型业务场景操作手册

A

每日自动资讯站

  1. 内容工厂 → AI 模型添加 Chat
  2. 创建分类、标题库、关键词库
  3. （可选）建知识库并同步切片
  4. 新建普通文章任务并启用
  5. 审核或等待自动发布
  6. 周报看诊断总览北极星 KPI
B

  1. 上传白皮书 PDF 到知识库
  2. RAG 沙箱验证召回效果
  3. 任务绑定知识库
  4. 编排模式选「编辑部 Pipeline」
C

多站点同步 WordPress

  1. 新建 WordPress 分发渠道
  2. 任务选「本站 + 分发」
  3. 发布后自动入分发队列
  4. 分发管理排查失败项
D

技术品牌 Wiki → Gweb

  1. 维护 P0 技术 IP 资产卡
  2. 新建 GWeb Wiki 渠道
  3. 任务选 Wiki MDX 格式
  4. 通过评分/合规后发布并同步
  5. 诊断总览查看同步与参数一致率
E

AIVIS 补缺闭环

  1. 数据采集配置真实 API + strict
  2. 问题库维护对比/决策题
  3. 全量扫描 → 看北极星 KPI
  4. 场景图谱对高缺口「创建补缺 Task」
  5. 发布分发后等待再扫，看 ΔTop3
  6. 诊断报告复盘闭环验证章
F

单篇精修活动稿

  1. 文章管理 → 新建文章
  2. Markdown 编辑 + SEO 优化
  3. 通过审核 → 发布
  4. GEO 标准单篇重评（如需）

十、常见问题

Q1：创建任务时提示「尚未配置分类」
请先到 内容生产 → 素材管理 → 分类管理 创建至少一个分类。
Q2：知识库一直显示「待向量化」
  1. 确认已在 内容工厂 → AI 模型 中添加 Embedding 模型
  2. 点击知识库列表的 同步切片
  3. 仍失败请联系管理员查看后台日志
Q3：任务启用后没有生成文章
检查：任务是否 已启用、标题库是否有剩余标题、是否已达 生成上限、队列是否有 失败 记录（运营总览 / 首页健康卡片）。
Q4：文章 GEO 显示「建议改进」还能发布吗？
默认是 软门禁：可发布，建议按评分建议改稿。仅当管理员开启硬门禁时，未通过才会拦截发布。内容门禁在 内容生产 → GEO 标准。
Q5：Wiki 内容没有出现在 Gweb
确认：任务为 Wiki MDX、渠道类型为 GWeb Wiki 且已启用、文章已 发布、合规/硬门禁（若开启）已通过、网站设置中 GWeb 同步 为已启用。
Q6：开启「人工审核」后无法设发布间隔
这是预期行为：审核模式下需人工确认后再发布，自动发布间隔不可用。
Q7：演示环境生成 / 探针质量很低
若 AI Mock 模式 已启用，或探针模式为语料/模拟，系统不会走真实大模型。正式使用需关闭 Mock，探针设为 api + strict，并配置真实 API Key。
Q8：北极星 Top3 为什么和 App 里搜到的不一样？
主 KPI 口径是 open_api（Chat API），不等于豆包/元宝等 App 联网搜索结果。报告中会用脚注说明偏移，不会用语料假数据覆盖主数字。
