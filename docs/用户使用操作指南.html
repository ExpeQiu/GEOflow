一、GEOFlow 是什么

GEOFlow 是一套 GEO（生成式引擎优化）内容工程平台，帮助团队用 AI 批量生产高质量内容，并结合知识库、任务调度与策略分析形成完整闭环。

核心能力
AI 批量生产 → 知识库 RAG → 任务调度 → 审核 · GEO 门禁 → 多站点分发 → 策略监控复盘

读者在哪里看内容？

运营模式读者访问
通用内容站本站公开前台（可选开启）
技术品牌 / Wiki 模式Gweb 独立 Wiki 站点（GEOFlow 负责生产与同步）
日常操作均在 管理后台（geoflow-admin） 完成，读者不直接访问后台。

5.2 创建任务前置检查清单

  • 至少一个 文章分类
  • 至少一个 标题库（库内有标题）
  • 至少一个 提示词模板 和 AI 聊天模型
  • 若使用知识库：Embedding 模型已配置且知识库已向量化
  • 若「仅分发」：至少一个 活跃分发渠道
  • 若 Wiki MDX：已配置 技术 IP 资产 与 GWeb Wiki 渠道

5.3 文章生命周期

AI 生成 / 手动创建 → 草稿 → 待审核 → 通过审核 → 发布 ↓ 回收站（可恢复/永久删除）

5.4 日常审核发布流程

  1. 文章列表 → 待审核 筛选
  2. 进入编辑页，检查标题、正文、SEO 字段
  3. 查看 GEO 评估：已通过 / 未通过 / 待评估
  4. 点击 通过审核 → 发布

八、典型业务场景操作手册

A

每日自动资讯站

  1. AI 配置器添加 Chat 模型
  2. 创建分类、标题库、关键词库
  3. （可选）建知识库并同步切片
  4. 新建普通文章任务并启用
  5. 审核或等待自动发布
  6. 周报查看数据分析与 GEO 诊断
B

知识库增强深度文章

  1. 上传白皮书 PDF 到知识库
  2. RAG 沙箱验证召回效果
  3. 任务绑定知识库
  4. 编排模式选「编辑部 Pipeline」
C

多站点同步 WordPress

  1. 新建 WordPress 分发渠道
  2. 任务选「本站 + 分发」
  3. 发布后自动入分发队列
  4. 分发管理排查失败项
D

技术品牌 Wiki → Gweb

  1. 维护 P0 技术 IP 资产卡
  2. 新建 GWeb Wiki 渠道
  3. 任务选 Wiki MDX 格式
  4. 通过 Wiki 合规门禁后自动同步
  5. 策略总览查看同步率 KPI
E

GEO 监控优化闭环

  1. 添加 10–20 个探针问题
  2. 每周全量扫描
  3. GEO 诊断处理失败 Top
  4. 仿真批量优化低分文章
  5. 洞察模板更新 Prompt
F

单篇精修活动稿

  1. 文章管理 → 新建文章
  2. Markdown 编辑 + SEO 优化
  3. 通过审核 → 发布
  4. GEO 诊断单篇重评

场景 D 详解：技术品牌 Wiki 同步流程

技术 IP 资产 → Wiki MDX 任务 → LangGraph 生成 → Wiki 合规门禁 → 发布 → Gweb 同步 → 读者访问 Wiki

十、常见问题

Q1：创建任务时提示「尚未配置分类」
请先到 内容生产 → 素材管理 → 分类管理 创建至少一个分类。
Q2：知识库一直显示「待向量化」
  1. 确认已在 AI 配置器中添加 Embedding 模型
  2. 点击知识库列表的 同步切片
  3. 仍失败请联系管理员查看后台日志
Q3：任务启用后没有生成文章
检查：任务是否 已启用、标题库是否有剩余标题、是否已达 生成上限、队列是否有 失败 记录（运营总览 / 首页健康卡片）。
Q4：文章 GEO 评估未通过无法发布
  1. 进入 策略与分析 → GEO 诊断 查看失败原因
  2. 编辑文章补充结构（FAQ、内链、摘要等）
  3. 单篇 重新评估 或批量重评
Q5：Wiki 内容没有出现在 Gweb
确认：任务为 Wiki MDX、渠道类型为 GWeb Wiki 且已启用、文章已 发布、Wiki 合规门禁已通过、网站设置中 GWeb 同步 为已启用。
Q6：开启「人工审核」后无法设发布间隔
这是预期行为：审核模式下需人工确认后再发布，自动发布间隔不可用。
Q7：演示环境生成内容质量很低
若 AI Mock 模式 已启用，系统不调用真实大模型。正式使用需关闭 Mock 并配置真实 API Key。

十一、每日 / 每周操作建议

每日（约 10 分钟）
  • 打开首页，查看任务队列与待审文章数
  • 处理 待审核 文章
  • 检查分发失败项并处理
每周（约 30 分钟）
  • 监控问题库执行一次 全量扫描
  • 查看 数据分析 与热门内容
  • GEO 诊断 处理失败 Top 原因
  • 补充标题库、更新知识库文档
  • 检查技术品牌 KPI（若适用）
