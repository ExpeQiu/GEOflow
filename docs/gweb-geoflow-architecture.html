主链路（技术品牌模式）

TechIpAsset → Wiki Task + RAG → AI 生成 Article → 审核 → Wiki GEO 门禁 → 发布 (distribution_only) → GwebWikiPublisher → Gweb MDX → SSR + Schema

策略闭环（Strategy Hub）

监控问题库命中 → 关联 TechIpAsset → 一键创建 Wiki Task · 采纳率下降 → 资产标记「需更新」→ 重新生成 → Gweb 同步

Wiki Task 约束（减法收敛）

规则说明
publish_scope仅允许 distribution_only
分发渠道gweb_wiki 或 generic_http_api；禁止 geoflow_agent
本站前台Wiki 不在 GEOFlow Blade 对外展示
可选关闭GEOFLOW_PUBLIC_SITE_ENABLED=false
真相源wiki_meta 对齐 Gweb frontmatter
